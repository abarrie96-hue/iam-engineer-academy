# IAM Engineer Academy

## 90-Day Identity and Access Management Engineering Program

A hands-on training and portfolio project designed to develop practical Identity and Access Management (IAM) engineering skills.

### Technologies Covered

- Windows Server Active Directory
- Microsoft Entra ID
- AWS IAM
- Okta
- SailPoint IGA concepts
- CyberArk PAM concepts
- PowerShell and Python
- Terraform and GitHub Actions

## Learning Objectives

- Implement authentication and authorization controls.
- Design RBAC and ABAC access models.
- Manage Joiner, Mover, and Leaver workflows.
- Configure identity federation and Single Sign-On.
- Automate identity provisioning and deprovisioning.
- Troubleshoot production IAM incidents.
- Apply least privilege and Separation of Duties.
- Document security controls and audit evidence.

## Enterprise Scenario

Labs and exercises use a fictional organization named **ACME Financial** to simulate enterprise IAM environments, access requests, governance workflows, and production incidents.

## Security

This repository uses fictional identities and sanitized examples. No real credentials, access tokens, private keys, or sensitive employee data should be committed.

## Goal

Build a practical, documented IAM engineering portfolio demonstrating technical implementation, security awareness, troubleshooting, and operational readiness.
